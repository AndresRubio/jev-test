# local-jev Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `local-jev`: a local, open-weight decision service in the style of TypeSafe's Jev, running Laya on MLX. Claude Code and other agents reach it over MCP, a Jev-compatible REST API, or a CLI.

**Architecture:**
- One Python process (`local-jev serve`) listens on 127.0.0.1:7711.
- A Starlette app, behind loopback-only security middleware, serves the REST routes and mounts the MCP Python SDK's Streamable HTTP app at `/mcp`.
- REST and MCP both call one `DecisionService`. It validates Jev requests, applies the guard layer, runs the engine on a single inference worker thread, shapes Jev-compatible answers, and logs metadata.
- The default engine wraps `laya_mlx.Router` on pinned, checksum-verified weights. A remote engine forwards requests to any Jev-compatible URL.

**Tech Stack:** Python 3.12 (uv), laya-mlx 0.4.0 (MLX), mcp 2.3.0 (`MCPServer`), Starlette 1.x and uvicorn, httpx2, huggingface-hub, tokenizers, pytest with anyio, ruff.

**Spec:** `docs/superpowers/specs/2026-09-25-local-jev-design.md`, including the §15 amendments.

```python
"""Errors shared by the service, the engines and the runtime."""

from __future__ import annotations

from typing import Any


class ServiceError(Exception):
    """An error the REST and MCP front ends report to the caller."""

    def __init__(self, status: int, code: str, message: str, hint: str = "") -> None:
        super().__init__(message)
        self.status = status
        self.code = code
        self.message = message
        self.hint = hint

    def to_dict(self) -> dict[str, Any]:
        return {"error": {"code": self.code, "message": self.message, "hint": self.hint}}

    def for_model(self) -> str:
        text = f"{self.code}: {self.message}"
        return f"{text} Hint: {self.hint}" if self.hint else text


def invalid(message: str, hint: str = "") -> ServiceError:
    return ServiceError(422, "invalid_request", message, hint)


def too_large(message: str, hint: str = "") -> ServiceError:
    return ServiceError(413, "too_large", message, hint)


class ModelUnavailable(Exception):
    """The engine cannot answer right now: weights missing, backend down or bad outputs."""

    def __init__(self, message: str, hint: str = "") -> None:
        super().__init__(message)
        self.message = message
        self.hint = hint


class NotDownloaded(ModelUnavailable):
    """A checkpoint is not in the local Hugging Face cache."""


class ChecksumMismatch(ModelUnavailable):
    """A weight file does not match its pinned size or SHA-256."""


class BusyError(Exception):
    """The inference queue is full."""


class RuntimeTimeout(Exception):
    """An inference job did not finish within its timeout."""
```

```python
"""Settings: defaults, then ~/.config/local-jev/config.toml, then LOCAL_JEV_* variables."""

from __future__ import annotations

import os
import re
import tomllib
from collections.abc import Mapping
from dataclasses import dataclass, field, replace
from pathlib import Path
from typing import Any

DEFAULT_CONFIG_PATH = Path("~/.config/local-jev/config.toml")
LAYA_REVISION = "c5d78730f3493e4fe16d61507ef4b78eef7318cf"
CHECKPOINT_NAMES = ("english", "multilingual", "typed-decisions")


class ConfigError(ValueError):
    """The configuration file or the environment holds an invalid value."""


@dataclass(frozen=True)
class LayaSettings:
    repo: str = "convaiinnovations/laya"
    revision: str = LAYA_REVISION
    dtype: str = "float16"
    prefetch: tuple[str, ...] = ("english", "multilingual")


@dataclass(frozen=True)
class BatchSettings:
    allowed_roots: tuple[Path, ...] = (Path.home(),)
    max_items: int = 5000
    max_file_bytes: int = 50 * 1024 * 1024
    max_evaluations: int = 20_000
    group_size: int = 32
    timeout_seconds: float = 300.0


@dataclass(frozen=True)
class RemoteSettings:
    url: str = ""
    api_key_env: str = ""


@dataclass(frozen=True)
class Settings:
    port: int = 7711
    backend: str = "laya-mlx"
    idle_unload_minutes: float = 15.0
    noul_mode: str = "native"
    log_inputs: bool = False
    token: str | None = None
    request_timeout_seconds: float = 30.0
    queue_limit: int = 64
    log_dir: Path = Path.home() / "Library" / "Logs" / "local-jev"
    results_dir: Path = Path.home() / "Library" / "Caches" / "local-jev" / "results"
    laya: LayaSettings = field(default_factory=LayaSettings)
    batch: BatchSettings = field(default_factory=BatchSettings)
    remote: RemoteSettings = field(default_factory=RemoteSettings)


_TOP: dict[str, Any] = {
    "port": int,
    "backend": str,
    "idle_unload_minutes": float,
    "noul_mode": str,
    "log_inputs": bool,
    "request_timeout_seconds": float,
    "queue_limit": int,
    "log_dir": Path,
    "results_dir": Path,
}
_SECTIONS: dict[str, tuple[type, dict[str, Any]]] = {
    "laya": (LayaSettings, {"repo": str, "revision": str, "dtype": str, "prefetch": "names"}),
    "batch": (
        BatchSettings,
        {
            "allowed_roots": "paths",
            "max_items": int,
            "max_file_bytes": int,
            "max_evaluations": int,
            "group_size": int,
            "timeout_seconds": float,
        },
    ),
    "remote": (RemoteSettings, {"url": str, "api_key_env": str}),
}
_ENV: dict[str, tuple[str, Any]] = {
    "LOCAL_JEV_PORT": ("port", int),
    "LOCAL_JEV_BACKEND": ("backend", str),
    "LOCAL_JEV_IDLE_UNLOAD_MINUTES": ("idle_unload_minutes", float),
    "LOCAL_JEV_NOUL_MODE": ("noul_mode", str),
    "LOCAL_JEV_LOG_INPUTS": ("log_inputs", bool),
    "LOCAL_JEV_TOKEN": ("token", str),
    "LOCAL_JEV_LOG_DIR": ("log_dir", Path),
    "LOCAL_JEV_RESULTS_DIR": ("results_dir", Path),
}


def load_settings(path: Path | None = None, env: Mapping[str, str] | None = None) -> Settings:
    """Defaults, overlaid by the TOML file when it exists, overlaid by LOCAL_JEV_* variables."""
    env = os.environ if env is None else env
    if path is None:
        path = Path(env.get("LOCAL_JEV_CONFIG") or DEFAULT_CONFIG_PATH)
    path = path.expanduser()
    data: dict[str, Any] = {}
    if path.exists():
        try:
            with path.open("rb") as fh:
                data = tomllib.load(fh)
        except tomllib.TOMLDecodeError as exc:
            raise ConfigError(f"{path}: {exc}") from exc
    settings = _apply_env(_from_mapping(data, path), env)
    _validate(settings)
    return settings


def _from_mapping(data: dict[str, Any], source: Path) -> Settings:
    top: dict[str, Any] = {}
    sections: dict[str, Any] = {}
    for key, value in data.items():
        if key in _SECTIONS:
            cls, types = _SECTIONS[key]
            if not isinstance(value, dict):
                raise ConfigError(f"{source}: [{key}] must be a table")
            kwargs = {}
            for sub, sub_value in value.items():
                if sub not in types:
                    raise ConfigError(f"{source}: unknown setting {key}.{sub}")
                kwargs[sub] = _coerce(types[sub], sub_value, f"{key}.{sub}")
            sections[key] = cls(**kwargs)
        elif key in _TOP:
            top[key] = _coerce(_TOP[key], value, key)
        else:
            raise ConfigError(f"{source}: unknown setting {key!r}")
    return Settings(**top, **sections)


def _apply_env(settings: Settings, env: Mapping[str, str]) -> Settings:
    changes = {name: _coerce(kind, env[var], var) for var, (name, kind) in _ENV.items() if env.get(var)}
    settings = replace(settings, **changes)
    if env.get("LOCAL_JEV_REMOTE_URL"):
        settings = replace(settings, remote=replace(settings.remote, url=env["LOCAL_JEV_REMOTE_URL"]))
    return settings


def _coerce(kind: Any, value: Any, where: str) -> Any:
    if kind is bool:
        if isinstance(value, bool):
            return value
        if isinstance(value, str) and value.lower() in ("1", "true", "yes", "on"):
            return True
        if isinstance(value, str) and value.lower() in ("0", "false", "no", "off"):
            return False
        raise ConfigError(f"{where} must be true or false")
    if kind in (int, float):
        if isinstance(value, bool):
            raise ConfigError(f"{where} must be a number")
        try:
            return kind(value)
        except (TypeError, ValueError) as exc:
            raise ConfigError(f"{where} must be a number") from exc
    if kind is str:
        if not isinstance(value, str):
            raise ConfigError(f"{where} must be a string")
        return value
    if kind is Path:
        if not isinstance(value, str) or not value:
            raise ConfigError(f"{where} must be a path")
        return Path(value).expanduser()
    if kind in ("names", "paths"):
        if not isinstance(value, list) or not all(isinstance(v, str) and v for v in value):
            raise ConfigError(f"{where} must be a list of strings")
        return tuple(Path(v).expanduser() for v in value) if kind == "paths" else tuple(value)
    raise AssertionError(f"unhandled setting type for {where}")


def _validate(s: Settings) -> None:
    if not 1024 <= s.port <= 65535:
        raise ConfigError("port must be between 1024 and 65535")
    if s.backend not in ("laya-mlx", "remote"):
        raise ConfigError("backend must be 'laya-mlx' or 'remote'")
    if s.noul_mode not in ("native", "ab_labels"):
        raise ConfigError("noul_mode must be 'native' or 'ab_labels'")
    if s.idle_unload_minutes < 0:
        raise ConfigError("idle_unload_minutes must be 0 (never unload) or more")
    if s.request_timeout_seconds <= 0 or s.batch.timeout_seconds <= 0:
        raise ConfigError("timeouts must be positive")
    if s.queue_limit < 1 or s.batch.group_size < 1 or s.batch.max_items < 1:
        raise ConfigError("queue_limit, batch.group_size and batch.max_items must be at least 1")
    if s.laya.dtype not in ("float16", "float32"):
        raise ConfigError("laya.dtype must be 'float16' or 'float32'")
    if not re.fullmatch(r"[0-9a-f]{40}", s.laya.revision):
        raise ConfigError("laya.revision must be a full 40-character commit hash")
    unknown = sorted(set(s.laya.prefetch) - set(CHECKPOINT_NAMES))
    if unknown:
        raise ConfigError(f"laya.prefetch has unknown checkpoints: {unknown}")
    if s.backend == "remote" and not s.remote.url:
        raise ConfigError("backend 'remote' needs remote.url (or LOCAL_JEV_REMOTE_URL)")
```

```python
"""Validate Jev /v1/systemone requests (https://docs.typesafe.ai/api.md) with fix-it hints."""

from __future__ import annotations

import json
from dataclasses import dataclass
from typing import Any

from local_jev.errors import invalid, too_large

QUESTION_TYPES = ("noul", "choice", "score")
MAX_QUESTIONS = 50
MAX_STATE_CHARS = 200_000
MAX_CHOICE_OPTIONS = 255
MODEL_HINT = "use auto, english, multilingual or typed-decisions"
CHOICE_EXAMPLE = 'e.g. {"billing": "invoices, refunds", "technical": "bugs, outages"}'


@dataclass(frozen=True)
class DecideRequest:
    state: Any
    questions: dict[str, dict[str, Any]]
    model: str = "auto"


def parse_decide_request(body: Any, *, max_questions: int = MAX_QUESTIONS) -> DecideRequest:
    if not isinstance(body, dict):
        raise invalid("the request body must be a JSON object", 'send {"state": ..., "questions": {...}}')
    if "state" not in body:
        raise invalid("missing 'state'", "state is the text, object or array the questions are about")
    state = parse_state(body["state"])
    questions = parse_questions(body.get("questions"), max_questions=max_questions)
    return DecideRequest(state=state, questions=questions, model=parse_model(body.get("model")))


def parse_state(state: Any) -> Any:
    if not isinstance(state, (str, dict, list)):
        raise invalid("'state' must be a string, object or array", "wrap numbers and booleans in an object")
    if isinstance(state, str) and not state.strip():
        raise invalid("'state' is empty", "send the text the questions are about")
    size = len(state) if isinstance(state, str) else len(json.dumps(state, ensure_ascii=False))
    if size > MAX_STATE_CHARS:
        raise too_large(
            f"'state' is {size} characters; the limit is {MAX_STATE_CHARS}",
            "send only the evidence the questions need, or use decide_batch with format=chunks",
        )
    return state


def parse_model(model: Any) -> str:
    if model is None:
        return "auto"
    if not isinstance(model, str) or not model.strip():
        raise invalid("'model' must be a non-empty string", MODEL_HINT)
    model = model.strip()
    return "auto" if model in ("auto", "jev-latest") else model


def parse_questions(questions: Any, *, max_questions: int = MAX_QUESTIONS) -> dict[str, dict[str, Any]]:
    if not isinstance(questions, dict) or not questions:
        raise invalid(
            "'questions' must be a non-empty object keyed by question id",
            'e.g. {"refund": {"type": "noul", "instructions": "Does the customer ask for money back?"}}',
        )
    if len(questions) > max_questions:
        raise too_large(
            f"{len(questions)} questions; the limit is {max_questions}", "split them across several calls"
        )
    parsed: dict[str, dict[str, Any]] = {}
    for qid, question in questions.items():
        if not qid.strip():
            raise invalid("question ids must be non-empty strings", 'use short ids such as "refund" or "dept"')
        parsed[qid] = _parse_question(qid, question)
    return parsed


def _parse_question(qid: str, question: Any) -> dict[str, Any]:
    if not isinstance(question, dict):
        raise invalid(f"question {qid!r} must be an object", '{"type": ..., "instructions": ..., "criteria": ...}')
    qtype = question.get("type")
    if qtype not in QUESTION_TYPES:
        raise invalid(f"question {qid!r} has type {qtype!r}", "type must be 'noul' (yes/no), 'choice' or 'score'")
    if not _non_empty(question.get("instructions")):
        raise invalid(f"question {qid!r} has no instructions", "say exactly what to decide, phrased positively")
    if qtype != "noul" and "labels" in question:
        raise invalid(f"question {qid!r}: labels are only supported on noul questions", "remove 'labels'")
    parsed: dict[str, Any] = {"type": qtype, "instructions": question["instructions"]}
    criteria = question.get("criteria")
    if qtype == "noul":
        if criteria is not None:
            if not isinstance(criteria, dict) or not criteria or not set(criteria) <= {"true", "false"}:
                raise invalid(
                    f"question {qid!r}: noul criteria may only use the keys 'true' and 'false'",
                    'e.g. {"true": "the customer asks for a refund", "false": "anything else"}',
                )
            parsed["criteria"] = criteria
        if "labels" in question:
            parsed["labels"] = _parse_labels(qid, question["labels"])
    elif qtype == "choice":
        options = _choice_options(qid, criteria)
        if len(options) < 2:
            raise invalid(f"question {qid!r} needs at least 2 options", CHOICE_EXAMPLE)
        if len(options) > MAX_CHOICE_OPTIONS:
            raise too_large(
                f"question {qid!r} has {len(options)} options; the limit is {MAX_CHOICE_OPTIONS}",
                "split it into a coarse question and a fine question",
            )
        parsed["criteria"] = criteria
    else:
        if not isinstance(criteria, list) or not 2 <= len(criteria) <= 10:
            raise invalid(
                f"question {qid!r}: score criteria must be a list of 2 to 10 levels",
                'e.g. ["not urgent", "soon", "blocking"]',
            )
        for index, level in enumerate(criteria):
            if not _non_empty(level):
                raise invalid(
                    f"question {qid!r}: score level {index} has no description", "every level needs a description"
                )
        parsed["criteria"] = criteria
    return parsed


def _parse_labels(qid: str, labels: Any) -> dict[str, str]:
    valid = (
        isinstance(labels, dict)
        and set(labels) == {"true", "false"}
        and all(isinstance(value, str) and value.strip() for value in labels.values())
        and labels["true"].strip() != labels["false"].strip()
    )
    if not valid:
        raise invalid(
            f"question {qid!r}: labels must map 'true' and 'false' to two different non-empty strings",
            'e.g. {"true": "A", "false": "B"}',
        )
    return labels


def _choice_options(qid: str, criteria: Any) -> list[str]:
    if isinstance(criteria, list):
        if not all(isinstance(option, str) and option.strip() for option in criteria):
            raise invalid(f"question {qid!r}: choice options must be non-empty strings", CHOICE_EXAMPLE)
        if len(set(criteria)) != len(criteria):
            raise invalid(f"question {qid!r}: choice options must be unique", "remove the duplicate labels")
        return list(criteria)
    if isinstance(criteria, dict):
        for label, description in criteria.items():
            if not label.strip():
                raise invalid(f"question {qid!r}: choice labels must be non-empty", CHOICE_EXAMPLE)
            if description is not None and not isinstance(description, (str, dict, list)):
                raise invalid(
                    f"question {qid!r}: option {label!r} must be described by a string, object, array or null",
                    CHOICE_EXAMPLE,
                )
        return list(criteria)
    raise invalid(
        f"question {qid!r}: choice criteria must be a list of labels or an object of label -> description",
        CHOICE_EXAMPLE,
    )


def _non_empty(value: Any) -> bool:
    if isinstance(value, str):
        return bool(value.strip())
    return isinstance(value, (dict, list)) and bool(value)
```

```python
"""The interface every backend implements.

decide(), count_tokens(), prefetch() and unload() may block. decide() and unload() always run
on the single inference worker thread. status() and is_loaded() must be cheap and thread-safe.
"""

from __future__ import annotations

from dataclasses import dataclass, field
from typing import Any, Protocol


@dataclass(frozen=True)
class EngineCapabilities:
    laya_guards: bool  # understands Laya's noul labels and reports truncation in usage


@dataclass
class EngineResult:
    answers: dict[str, dict[str, Any]]
    usage: dict[str, Any]
    model: str
    checkpoint: str | None = None
    routing_reason: str | None = None
    shortlist: dict[str, dict[str, Any]] = field(default_factory=dict)


class Engine(Protocol):
    name: str
    capabilities: EngineCapabilities

    def decide(self, state: Any, questions: dict[str, dict[str, Any]], model: str) -> EngineResult: ...

    def count_tokens(self, text: str, model: str) -> int: ...

    def prefetch(self, names: tuple[str, ...]) -> None: ...

    def is_loaded(self) -> bool: ...

    def unload(self) -> None: ...

    def status(self) -> dict[str, Any]: ...
```

```python
"""A deterministic stand-in for a real engine: no weights, no MLX."""

from __future__ import annotations

import threading
import time
from typing import Any

from local_jev.engines.base import EngineCapabilities, EngineResult


class FakeEngine:
    """Answers from keywords: noul is 0.9 when the state says "yes"; choice picks a mentioned label."""

    name = "fake"
    capabilities = EngineCapabilities(laya_guards=True)

    def __init__(
        self,
        *,
        usage_extra: dict[str, Any] | None = None,
        shortlist: dict[str, dict[str, Any]] | None = None,
        fail_with: BaseException | None = None,
        block: threading.Event | None = None,
        delay: float = 0.0,
    ) -> None:
        self.usage_extra = usage_extra or {}
        self.shortlist = shortlist or {}
        self.fail_with = fail_with
        self.block = block
        self.delay = delay
        self.calls: list[tuple[Any, dict[str, Any], str]] = []
        self.loaded = False
        self.unload_calls = 0
        self.prefetched: list[str] = []
        self.active = 0
        self.max_active = 0
        self._lock = threading.Lock()

    def decide(self, state: Any, questions: dict[str, dict[str, Any]], model: str) -> EngineResult:
        with self._lock:
            self.active += 1
            self.max_active = max(self.max_active, self.active)
        try:
            if self.block is not None:
                self.block.wait(5)
            if self.delay:
                time.sleep(self.delay)
            self.calls.append((state, questions, model))
            if self.fail_with is not None:
                raise self.fail_with
            self.loaded = True
            text = str(state).lower()
            answers = {qid: _answer(question, text) for qid, question in questions.items()}
            usage = {"input_tokens": 10 * len(questions), "output_tokens": 0, **self.usage_extra}
            return EngineResult(
                answers=answers,
                usage=usage,
                model="fake-model",
                checkpoint="english",
                routing_reason="fake routing",
                shortlist=dict(self.shortlist),
            )
        finally:
            with self._lock:
                self.active -= 1

    def count_tokens(self, text: str, model: str) -> int:
        return len(text.split())

    def prefetch(self, names: tuple[str, ...]) -> None:
        self.prefetched.extend(names)

    def is_loaded(self) -> bool:
        return self.loaded

    def unload(self) -> None:
        self.unload_calls += 1
        self.loaded = False

    def status(self) -> dict[str, Any]:
        return {"backend": "fake", "loaded": ["english"] if self.loaded else [], "ready": ["english"]}


def _answer(question: dict[str, Any], text: str) -> dict[str, Any]:
    action = {"act_probability": 1.0}
    if question["type"] == "noul":
        p = 0.9 if "yes" in text else 0.1
        confidence = max(p, 1 - p)
        return {"type": "noul", "noul": p, "confidence": confidence, "answer_confidence": confidence, "action": action}
    if question["type"] == "choice":
        labels = list(question["criteria"])
        chosen = next((label for label in labels if label.lower() in text), labels[0])
        rest = round(0.2 / (len(labels) - 1), 4)
        probabilities = {label: (0.8 if label == chosen else rest) for label in labels}
        return {
            "type": "choice",
            "choice": chosen,
            "probabilities": probabilities,
            "confidence": 0.5,
            "answer_confidence": 0.8,
            "action": action,
        }
    levels = question["criteria"]
    top = len(levels) - 1
    rest = round(0.3 / top, 4)
    probabilities = {str(i): (0.7 if i == top else rest) for i in range(len(levels))}
    score = round(sum(i * p for i, p in enumerate(probabilities.values())), 4)
    return {
        "type": "score",
        "score": score,
        "legend": {str(i): level for i, level in enumerate(levels)},
        "probabilities": probabilities,
        "confidence": 0.4,
        "answer_confidence": 0.7,
        "action": action,
    }
```

```python
"""Engine-agnostic request tweaks and response shaping (spec §7)."""

from __future__ import annotations

import copy
from typing import Any

from local_jev.engines.base import EngineResult
from local_jev.errors import ModelUnavailable

AB_LABELS = {"true": "A", "false": "B"}
JEV_FIELDS = {
    "noul": ("type", "noul", "confidence"),
    "choice": ("type", "choice", "probabilities", "confidence"),
    "score": ("type", "score", "legend", "probabilities", "confidence"),
}
TRUNCATION_HINT = "use decide_batch with format=chunks, or model=multilingual"
BACKEND_HINT = "check that the backend speaks Jev's /v1/systemone format"


def prepare_questions(
    questions: dict[str, dict[str, Any]], *, noul_mode: str, laya_guards: bool
) -> dict[str, dict[str, Any]]:
    """A deep copy of the questions with the model-facing tweaks applied."""
    prepared = copy.deepcopy(questions)
    if laya_guards and noul_mode == "ab_labels":
        for question in prepared.values():
            if question["type"] == "noul" and "labels" not in question:
                question["labels"] = dict(AB_LABELS)
    return prepared


def answer_confidence(answer: dict[str, Any]) -> float:
    """Probability of the reported answer: max(p) for choice/score, max(p, 1 - p) for noul."""
    if "answer_confidence" in answer:
        return round(float(answer["answer_confidence"]), 4)
    if answer.get("type") == "noul":
        p = float(answer["noul"])
        return round(max(p, 1.0 - p), 4)
    probabilities = answer.get("probabilities") or {}
    if probabilities:
        return round(max(float(value) for value in probabilities.values()), 4)
    return round(float(answer.get("confidence", 0.0)), 4)


def finalize(
    result: EngineResult, questions: dict[str, dict[str, Any]], *, backend: str, latency_ms: float
) -> dict[str, Any]:
    """Turn an engine result into the public, Jev-compatible response."""
    per_question = _usage_warnings(result.usage)
    answers: dict[str, dict[str, Any]] = {}
    local_warnings: list[str] = []
    for qid, question in questions.items():
        raw = result.answers.get(qid)
        if raw is None:
            raise ModelUnavailable(f"the backend returned no answer for question {qid!r}", BACKEND_HINT)
        qtype = raw.get("type", question["type"])
        if qtype not in JEV_FIELDS:
            raise ModelUnavailable(f"the backend returned an unknown answer type {qtype!r} for {qid!r}", BACKEND_HINT)
        answer = {key: raw[key] for key in JEV_FIELDS[qtype] if key in raw}
        answer["type"] = qtype
        answer["answer_confidence"] = answer_confidence(raw)
        warnings = list(per_question.get(qid, []))
        meta = result.shortlist.get(qid)
        if meta and not meta.get("passthrough", True):
            kept = list(meta["labels"])
            answer["shortlisted"] = {"kept": kept, "dropped": int(meta["n"]) - len(kept)}
            warnings.append(
                f"shortlisted: {meta['n']} options were narrowed to the {len(kept)} most similar to the input; "
                "probabilities cover only those"
            )
        answer["warnings"] = warnings
        local_warnings.extend(f"{qid}: {warning}" for warning in warnings)
        answers[qid] = answer
    usage = {
        "input_tokens": int(result.usage.get("input_tokens", 0)),
        "output_tokens": int(result.usage.get("output_tokens", 0)),
    }
    local: dict[str, Any] = {
        "backend": backend,
        "checkpoint": result.checkpoint,
        "routing_reason": result.routing_reason,
        "latency_ms": round(latency_ms, 1),
        "warnings": local_warnings,
    }
    extra = {key: value for key, value in result.usage.items() if key not in usage}
    if extra:
        local["usage"] = extra
    return {"model": result.model, "answers": answers, "usage": usage, "local": local}


def compact_answers(answers: dict[str, dict[str, Any]]) -> dict[str, dict[str, Any]]:
    """Just the answer value and its confidence, for logs and batch results."""
    return {
        qid: {answer["type"]: answer[answer["type"]], "answer_confidence": answer["answer_confidence"]}
        for qid, answer in answers.items()
    }


def warning_code(warning: str) -> str:
    return warning.split(":", 1)[0]


def _usage_warnings(usage: dict[str, Any]) -> dict[str, list[str]]:
    warnings: dict[str, list[str]] = {}
    if usage.get("truncated"):
        message = (
            f"state_truncated: {usage.get('state_tokens_dropped', 0)} of {usage.get('state_tokens', 0)} "
            f"input tokens did not fit and were ignored; {TRUNCATION_HINT}"
        )
        for qid in usage.get("truncated_questions") or []:
            warnings.setdefault(qid, []).append(message)
    for qid, info in (usage.get("options") or {}).items():
        warnings.setdefault(qid, []).append(
            f"options_collapsed: only {info.get('distinct')} of {info.get('total')} options stayed distinct; "
            "shorten option descriptions or split the question"
        )
    return warnings
```

```python
"""One inference worker thread: jobs never overlap, the queue is bounded, idle models unload."""

from __future__ import annotations

import asyncio
import threading
import time
from collections import deque
from collections.abc import Callable
from concurrent.futures import Future, ThreadPoolExecutor
from typing import Any, TypeVar

from local_jev.engines.base import Engine
from local_jev.errors import BusyError, RuntimeTimeout

T = TypeVar("T")


class Runtime:
    def __init__(
        self,
        engine: Engine,
        *,
        queue_limit: int = 64,
        idle_unload_seconds: float = 900.0,
        clock: Callable[[], float] = time.monotonic,
    ) -> None:
        self.idle_unload_seconds = idle_unload_seconds
        self._engine = engine
        self._queue_limit = queue_limit
        self._clock = clock
        self._executor = ThreadPoolExecutor(max_workers=1, thread_name_prefix="local-jev-inference")
        self._lock = threading.Lock()
        self._pending = 0
        self._last_used = clock()
        self._unload_scheduled = False
        self._latencies: dict[str, deque[float]] = {}

    @property
    def pending(self) -> int:
        with self._lock:
            return self._pending

    async def run(self, job: Callable[[Engine], T], *, timeout: float, kind: str = "decide") -> T:
        """Run job(engine) on the worker thread; never more than one job at a time."""
        with self._lock:
            if self._pending >= self._queue_limit:
                raise BusyError(f"{self._pending} requests are already queued")
            self._pending += 1
        future = self._executor.submit(self._execute, job, kind)
        future.add_done_callback(self._release)
        try:
            return await asyncio.wait_for(asyncio.wrap_future(future), timeout)
        except TimeoutError as exc:
            raise RuntimeTimeout(f"no answer within {timeout:g} s") from exc

    def check_idle(self) -> bool:
        """Schedule an unload when nothing ran for idle_unload_seconds. Returns True if scheduled."""
        if self.idle_unload_seconds <= 0:
            return False
        with self._lock:
            idle = self._clock() - self._last_used
            if self._pending or self._unload_scheduled or idle < self.idle_unload_seconds:
                return False
            self._unload_scheduled = True
        if not self._engine.is_loaded():
            with self._lock:
                self._unload_scheduled = False
            return False
        self._executor.submit(self._unload)
        return True

    def stats(self) -> dict[str, Any]:
        with self._lock:
            pending = self._pending
            idle = self._clock() - self._last_used
            samples = list(self._latencies.get("decide", ()))
        return {
            "queue_depth": pending,
            "idle_seconds": round(idle, 1),
            "idle_unload_seconds": self.idle_unload_seconds,
            "decide_latency_ms": _percentiles(samples),
        }

    def shutdown(self) -> None:
        self._executor.shutdown(wait=False, cancel_futures=True)

    def _execute(self, job: Callable[[Engine], T], kind: str) -> T:
        start = self._clock()
        try:
            return job(self._engine)
        finally:
            elapsed_ms = (self._clock() - start) * 1000
            with self._lock:
                self._latencies.setdefault(kind, deque(maxlen=1000)).append(elapsed_ms)
                self._last_used = self._clock()

    def _release(self, _future: Future[Any]) -> None:
        with self._lock:
            self._pending -= 1
            self._last_used = self._clock()

    def _unload(self) -> None:
        try:
            self._engine.unload()
        finally:
            with self._lock:
                self._unload_scheduled = False


def _percentiles(samples: list[float]) -> dict[str, Any]:
    if not samples:
        return {"count": 0, "p50": None, "p95": None}
    ordered = sorted(samples)

    def pick(q: float) -> float:
        return round(ordered[min(len(ordered) - 1, round(q * (len(ordered) - 1)))], 1)

    return {"count": len(ordered), "p50": pick(0.5), "p95": pick(0.95)}
```

```python
"""Pinned Laya checkpoints: where they live in the Hugging Face cache, download and verification."""

from __future__ import annotations

import hashlib
from dataclasses import dataclass
from pathlib import Path

from huggingface_hub import constants, snapshot_download

from local_jev.errors import ChecksumMismatch, NotDownloaded

FILES = ("model.safetensors", "rl_agent_config.json", "encoder/config.json", "tokenizer/*", "mlx_config.json")
REQUIRED = ("model.safetensors", "rl_agent_config.json", "encoder/config.json", "tokenizer/tokenizer.json")
PULL_HINT = "run `local-jev pull` (add --all for typed-decisions)"


@dataclass(frozen=True)
class Checkpoint:
    name: str
    subfolder: str | None
    sha256: str
    size: int


CHECKPOINTS = {
    "english": Checkpoint(
        "english", None, "891102d372688fc2a094dac56a384bc537b87c63f21f9f3dac0be2b7cbc8d86c", 842_609_210
    ),
    "multilingual": Checkpoint(
        "multilingual", "multilingual", "9d628fd971b700382ac6f65920a86f149777b2e748e0c955fb3b19695aa8f204", 643_835_514
    ),
    "typed-decisions": Checkpoint(
        "typed-decisions",
        "typed-decisions",
        "4fa56de72383a9d3efa9cfa78955733c81b9fc8067a587ca4beb82c78107a24e",
        842_609_220,
    ),
}


def patterns(name: str) -> list[str]:
    subfolder = CHECKPOINTS[name].subfolder
    prefix = f"{subfolder}/" if subfolder else ""
    return [prefix + item for item in FILES]


def snapshot_root(repo: str, revision: str, cache_dir: Path | None = None) -> Path:
    base = Path(cache_dir) if cache_dir is not None else Path(constants.HF_HUB_CACHE)
    return base / f"models--{repo.replace('/', '--')}" / "snapshots" / revision


def checkpoint_dir(root: Path, name: str) -> Path:
    subfolder = CHECKPOINTS[name].subfolder
    return root / subfolder if subfolder else root


def is_complete(root: Path, name: str) -> bool:
    folder = checkpoint_dir(root, name)
    return all((folder / item).is_file() for item in REQUIRED)


def fetch(repo: str, revision: str, name: str, *, allow_download: bool, cache_dir: Path | None = None) -> Path:
    """Return the snapshot root holding `name`, downloading it first when allowed."""
    root = snapshot_root(repo, revision, cache_dir)
    if is_complete(root, name):
        return root
    if not allow_download:
        raise NotDownloaded(f"the {name} checkpoint is not downloaded", PULL_HINT)
    downloaded = Path(snapshot_download(repo, revision=revision, allow_patterns=patterns(name), cache_dir=cache_dir))
    if not is_complete(downloaded, name):
        raise NotDownloaded(f"the download of the {name} checkpoint is incomplete", PULL_HINT)
    return downloaded


def verify(root: Path, name: str, *, expected: Checkpoint | None = None) -> None:
    """Check the weight file against its pinned size and SHA-256."""
    expected = expected or CHECKPOINTS[name]
    path = checkpoint_dir(root, name) / "model.safetensors"
    hint = f"delete {path.parent} and run `local-jev pull`"
    size = path.stat().st_size
    if size != expected.size:
        raise ChecksumMismatch(f"{path} is {size} bytes, expected {expected.size}", hint)
    digest = hashlib.sha256()
    with path.open("rb") as fh:
        for block in iter(lambda: fh.read(8 << 20), b""):
            digest.update(block)
    if digest.hexdigest() != expected.sha256:
        raise ChecksumMismatch(f"{path} does not match its pinned SHA-256", hint)
```

```python
"""The default engine: laya-mlx's Router on pinned, verified Laya checkpoints."""

from __future__ import annotations

import threading
from collections.abc import Callable
from pathlib import Path
from typing import Any

from local_jev import checkpoints
from local_jev.config import LayaSettings
from local_jev.engines.base import EngineCapabilities, EngineResult
from local_jev.errors import ModelUnavailable

SHORTLIST_K = 20
UNKNOWN_MODEL_HINT = "use auto, english, multilingual or typed-decisions"


def _laya() -> Any:
    import laya_mlx

    return laya_mlx


def default_router_factory(root: Path, dtype: str) -> Any:
    """A Router whose checkpoints point at the pinned snapshot instead of the Hub's newest revision."""
    models = {
        name: (str(root), checkpoint.subfolder) if checkpoint.subfolder else str(root)
        for name, checkpoint in checkpoints.CHECKPOINTS.items()
    }
    return _laya().Router(models=models, max_loaded=2, default="english", dtype=dtype)


def default_tokenizer_factory(path: Path) -> Any:
    from tokenizers import Tokenizer

    return Tokenizer.from_file(str(path))


class LayaMLXEngine:
    name = "laya-mlx"
    capabilities = EngineCapabilities(laya_guards=True)

    def __init__(
        self,
        settings: LayaSettings,
        *,
        cache_dir: Path | None = None,
        router_factory: Callable[[Path, str], Any] = default_router_factory,
        shortlist_fn: Callable[..., dict[str, Any]] | None = None,
        embed_factory: Callable[[Any], Any] | None = None,
        tokenizer_factory: Callable[[Path], Any] = default_tokenizer_factory,
    ) -> None:
        self._settings = settings
        self._cache_dir = cache_dir
        self._root = checkpoints.snapshot_root(settings.repo, settings.revision, cache_dir)
        self._router_factory = router_factory
        self._shortlist = shortlist_fn or (lambda *args, **kwargs: _laya().predict_shortlist(*args, **kwargs))
        self._embed_factory = embed_factory or (lambda agent: _laya().embed_fn_from_agent(agent))
        self._tokenizer_factory = tokenizer_factory
        self._router = router_factory(self._root, settings.dtype)
        self._lock = threading.Lock()
        self._ready: set[str] = set()
        self._downloading: set[str] = set()
        self._tokenizers: dict[str, Any] = {}

    def decide(self, state: Any, questions: dict[str, dict[str, Any]], model: str) -> EngineResult:
        name, reason = self._pick(state, questions, model)
        self._require(name)
        try:
            raw = self._predict(self._router, state, questions, name)
        except FloatingPointError:
            raw = self._predict_float32(state, questions, name)
        return EngineResult(
            answers=raw["answers"],
            usage=raw.get("usage", {}),
            model=f"laya-{name}",
            checkpoint=name,
            routing_reason=reason,
            shortlist=raw.get("shortlist", {}),
        )

    def count_tokens(self, text: str, model: str) -> int:
        name, _reason = self._pick(text, None, model)
        self._require(name)
        with self._lock:
            tokenizer = self._tokenizers.get(name)
            if tokenizer is None:
                path = checkpoints.checkpoint_dir(self._root, name) / "tokenizer" / "tokenizer.json"
                tokenizer = self._tokenizer_factory(path)
                self._tokenizers[name] = tokenizer
        return len(tokenizer.encode(text, add_special_tokens=False).ids)

    def prefetch(self, names: tuple[str, ...]) -> None:
        for name in names:
            with self._lock:
                if name in self._ready or name in self._downloading:
                    continue
                self._downloading.add(name)
            try:
                root = checkpoints.fetch(
                    self._settings.repo,
                    self._settings.revision,
                    name,
                    allow_download=True,
                    cache_dir=self._cache_dir,
                )
                checkpoints.verify(root, name)
                with self._lock:
                    self._ready.add(name)
            finally:
                with self._lock:
                    self._downloading.discard(name)

    def is_loaded(self) -> bool:
        return bool(self._router.loaded)

    def unload(self) -> None:
        self._router.unload()

    def status(self) -> dict[str, Any]:
        with self._lock:
            ready, downloading = sorted(self._ready), sorted(self._downloading)
        return {
            "backend": self.name,
            "repo": self._settings.repo,
            "revision": self._settings.revision,
            "dtype": self._settings.dtype,
            "loaded": list(self._router.loaded),
            "ready": ready,
            "downloading": downloading,
            "cache": str(self._root),
        }

    def _pick(self, state: Any, questions: dict[str, Any] | None, model: str) -> tuple[str, str | None]:
        if model == "auto":
            decision = self._router.route(state, questions)
            return decision["model"], decision.get("reason")
        try:
            return self._router.resolve(model), "requested"
        except ValueError as exc:
            raise ValueError(f"unknown model {model!r}; {UNKNOWN_MODEL_HINT}") from exc

    def _require(self, name: str) -> None:
        with self._lock:
            if name in self._ready:
                return
            downloading = name in self._downloading
        if downloading:
            raise ModelUnavailable(
                f"the {name} checkpoint is still being downloaded or verified", "retry in a minute"
            )
        root = checkpoints.fetch(
            self._settings.repo, self._settings.revision, name, allow_download=False, cache_dir=self._cache_dir
        )
        checkpoints.verify(root, name)
        with self._lock:
            self._ready.add(name)

    def _predict(self, router: Any, state: Any, questions: dict[str, dict[str, Any]], name: str) -> dict[str, Any]:
        if any(q["type"] == "choice" and len(q["criteria"]) > SHORTLIST_K for q in questions.values()):
            embed = self._embed_factory(router.load(name))
            return self._shortlist(router, state, questions, embed, k=SHORTLIST_K, model=name)
        return router.predict(state, questions, model=name)

    def _predict_float32(self, state: Any, questions: dict[str, dict[str, Any]], name: str) -> dict[str, Any]:
        router = self._router_factory(self._root, "float32")
        try:
            return self._predict(router, state, questions, name)
        except FloatingPointError as exc:
            raise ModelUnavailable(
                "the model produced non-finite outputs, even in float32", "rephrase or shorten the input"
            ) from exc
        finally:
            router.unload()
```

```python
"""Forward decisions to any Jev-compatible /v1/systemone endpoint: Kev, upstream laya-serve or hosted Jev."""

from __future__ import annotations

import math
from typing import Any

import httpx2

from local_jev.engines.base import EngineCapabilities, EngineResult
from local_jev.errors import ModelUnavailable

ENDPOINT_HINT = "is remote.url a Jev-compatible /v1/systemone endpoint?"


class RemoteJevEngine:
    name = "remote"
    capabilities = EngineCapabilities(laya_guards=False)

    def __init__(
        self,
        url: str,
        *,
        api_key: str | None = None,
        timeout: float = 30.0,
        transport: httpx2.BaseTransport | None = None,
    ) -> None:
        self._url = url
        self._api_key = api_key
        self._client = httpx2.Client(timeout=timeout, transport=transport)

    def decide(self, state: Any, questions: dict[str, dict[str, Any]], model: str) -> EngineResult:
        payload = {"model": "jev-latest" if model == "auto" else model, "state": state, "questions": questions}
        headers = {"Authorization": f"Bearer {self._api_key}"} if self._api_key else {}
        try:
            response = self._client.post(self._url, json=payload, headers=headers)
        except httpx2.HTTPError as exc:
            raise ModelUnavailable(
                f"the remote backend is unreachable: {exc}", "check remote.url and that the server is running"
            ) from exc
        if response.status_code == 422:
            raise ValueError(f"the remote backend rejected the request: {response.text[:500]}")
        if response.status_code in (401, 403):
            raise ModelUnavailable("the remote backend refused the API key", "check remote.api_key_env")
        if response.status_code >= 400:
            raise ModelUnavailable(f"the remote backend returned HTTP {response.status_code}", "retry later")
        try:
            data = response.json()
        except ValueError as exc:
            raise ModelUnavailable("the remote backend returned an unexpected payload", ENDPOINT_HINT) from exc
        if not isinstance(data, dict) or not isinstance(data.get("answers"), dict):
            raise ModelUnavailable("the remote backend returned an unexpected payload", ENDPOINT_HINT)
        return EngineResult(
            answers=data["answers"], usage=data.get("usage") or {}, model=str(data.get("model", "remote"))
        )

    def count_tokens(self, text: str, model: str) -> int:
        return max(1, math.ceil(len(text) / 4))

    def prefetch(self, names: tuple[str, ...]) -> None:
        return None

    def is_loaded(self) -> bool:
        return False

    def unload(self) -> None:
        return None

    def status(self) -> dict[str, Any]:
        return {"backend": self.name, "url": self._url, "api_key": bool(self._api_key)}
```

```python
"""Loopback-only access, an optional bearer token, and the file policy for decide_batch."""

from __future__ import annotations

import hmac
import json
from collections.abc import Awaitable, Callable, MutableMapping
from pathlib import Path
from typing import Any
from urllib.parse import urlsplit

from local_jev.errors import invalid, too_large

Scope = MutableMapping[str, Any]
Message = MutableMapping[str, Any]
Receive = Callable[[], Awaitable[Message]]
Send = Callable[[Message], Awaitable[None]]
ASGIApp = Callable[[Scope, Receive, Send], Awaitable[None]]

LOOPBACK_HOSTNAMES = ("127.0.0.1", "localhost", "::1")


def loopback_hosts(port: int) -> frozenset[str]:
    return frozenset({f"127.0.0.1:{port}", f"localhost:{port}", f"[::1]:{port}"})


def is_loopback_origin(origin: str) -> bool:
    parts = urlsplit(origin)
    return parts.scheme == "http" and parts.hostname in LOOPBACK_HOSTNAMES


class SecurityMiddleware:
    """Answer only requests addressed to this machine's loopback, not sent from web pages."""

    def __init__(self, app: ASGIApp, *, port: int, token: str | None = None) -> None:
        self.app = app
        self._port = port
        self._hosts = loopback_hosts(port)
        self._token = token

    async def __call__(self, scope: Scope, receive: Receive, send: Send) -> None:
        if scope["type"] != "http":
            await self.app(scope, receive, send)
            return
        headers = {key.decode("latin-1").lower(): value.decode("latin-1") for key, value in scope.get("headers", [])}
        if headers.get("host", "").lower() not in self._hosts:
            await _reject(
                send,
                421,
                "misdirected",
                "this server only answers requests addressed to its loopback address",
                f"use http://127.0.0.1:{self._port}",
            )
            return
        origin = headers.get("origin")
        if origin is not None and not is_loopback_origin(origin):
            await _reject(
                send,
                403,
                "forbidden_origin",
                "requests from web pages are not allowed",
                "call local-jev from a local program, not a browser",
            )
            return
        if self._token and scope.get("path") != "/health":
            supplied = headers.get("authorization", "").encode()
            if not hmac.compare_digest(supplied, f"Bearer {self._token}".encode()):
                await _reject(
                    send,
                    401,
                    "unauthorized",
                    "missing or wrong bearer token",
                    "send Authorization: Bearer $LOCAL_JEV_TOKEN",
                )
                return
        await self.app(scope, receive, send)


async def _reject(send: Send, status: int, code: str, message: str, hint: str) -> None:
    body = json.dumps({"error": {"code": code, "message": message, "hint": hint}}).encode()
    await send(
        {
            "type": "http.response.start",
            "status": status,
            "headers": [(b"content-type", b"application/json"), (b"content-length", str(len(body)).encode())],
        }
    )
    await send({"type": "http.response.body", "body": body})


class FilePolicy:
    """Which local files decide_batch may read."""

    def __init__(self, allowed_roots: tuple[Path, ...], max_bytes: int) -> None:
        self._roots = tuple(Path(root).expanduser().resolve() for root in allowed_roots)
        self._max_bytes = max_bytes

    def check(self, path: str) -> Path:
        candidate = Path(path)
        if not candidate.is_absolute():
            raise invalid(f"'path' must be absolute: {path!r}", "pass the full path, e.g. /Users/you/data/items.jsonl")
        try:
            resolved = candidate.resolve(strict=True)
        except (OSError, RuntimeError) as exc:
            raise invalid(f"no such file: {path}", "check the path") from exc
        if not any(resolved.is_relative_to(root) for root in self._roots):
            allowed = ", ".join(str(root) for root in self._roots)
            raise invalid(
                f"{path} is outside the allowed folders",
                f"allowed: {allowed}; change batch.allowed_roots in the config",
            )
        if not resolved.is_file():
            raise invalid(f"{path} is not a regular file", "point at a file, not a folder or a device")
        size = resolved.stat().st_size
        if size > self._max_bytes:
            raise too_large(f"{path} is {size} bytes; the limit is {self._max_bytes}", "split the file")
        return resolved
```

```python
import io
import json
import math
import secrets
import time
from collections.abc import Callable
from dataclasses import dataclass
from datetime import UTC, datetime
from pathlib import Path
from typing import Any

from local_jev.guard import compact_answers, warning_code
from local_jev.schema import parse_model, parse_questions

FORMATS = ("auto", "jsonl", "csv", "lines", "chunks")
FILTER_OPS = (">=", "<=", "==")
MAX_BATCH_QUESTIONS = 8
SNIPPET_CHARS = 200
RESULT_MAX_AGE_SECONDS = 7 * 24 * 3600
FILTER_EXAMPLE = '{"question": "relevant", "op": ">=", "value": 0.8}'


@dataclass(frozen=True)
class Filter:
    question: str
    op: str
    value: Any


@dataclass(frozen=True)
class BatchParams:
    questions: dict[str, dict[str, Any]]
    items: list[Any] | None
    path: str | None
    format: str
    field: str | None
    chunk_tokens: int
    filter: Filter | None
    top_k: int
    model: str


@dataclass(frozen=True)
class Item:
    id: Any
    n: int
    state: Any
    start_line: int | None = None
    end_line: int | None = None


def parse_batch_params(body: Any, *, max_items: int) -> BatchParams:
    if not isinstance(body, dict):
        raise invalid("the request body must be a JSON object", '{"questions": {...}, "path": "/abs/file.jsonl"}')
    questions = parse_questions(body.get("questions"), max_questions=MAX_BATCH_QUESTIONS)
    items, path = body.get("items"), body.get("path")
    if (items is None) == (path is None):
        raise invalid("pass exactly one of 'items' or 'path'", "items for a short inline list, path for a local file")
    if items is not None:
        if not isinstance(items, list) or not items:
            raise invalid("'items' must be a non-empty array", "or pass 'path' to read a file")
        if len(items) > max_items:
            raise too_large(f"{len(items)} items; the limit is {max_items}", "split the batch")
    elif not isinstance(path, str) or not path:
        raise invalid("'path' must be a non-empty string", "pass an absolute path to a local file")
    fmt = body.get("format", "auto")
    if fmt not in FORMATS:
        raise invalid(f"unknown format {fmt!r}", f"use one of {', '.join(FORMATS)}")
    field = body.get("field")
    if field is not None and (not isinstance(field, str) or not field.strip()):
        raise invalid("'field' must be a non-empty string", "a dotted JSON path such as body.text, or a CSV column")
    return BatchParams(
        questions=questions,
        items=items,
        path=path,
        format=fmt,
        field=field,
        chunk_tokens=_int_in_range(body.get("chunk_tokens", 256), "chunk_tokens", 32, 1024),
        filter=_parse_filter(body.get("filter"), questions),
        top_k=_int_in_range(body.get("top_k", 20), "top_k", 1, 200),
        model=parse_model(body.get("model")),
    )


def _int_in_range(value: Any, name: str, low: int, high: int) -> int:
    if not isinstance(value, int) or isinstance(value, bool) or not low <= value <= high:
        raise invalid(f"'{name}' must be an integer from {low} to {high}", f"got {value!r}")
    return value


def _parse_filter(raw: Any, questions: dict[str, dict[str, Any]]) -> Filter | None:
    if raw is None:
        return None
    if not isinstance(raw, dict) or set(raw) != {"question", "op", "value"}:
        raise invalid("'filter' must have exactly the keys question, op and value", FILTER_EXAMPLE)
    qid, op, value = raw["question"], raw["op"], raw["value"]
    if qid not in questions:
        raise invalid(f"filter question {qid!r} is not one of the questions", FILTER_EXAMPLE)
    if op not in FILTER_OPS:
        raise invalid(f"filter op {op!r} is not supported", "use >=, <= or ==")
    question = questions[qid]
    if question["type"] == "choice":
        if op != "==" or value not in list(question["criteria"]):
            raise invalid(
                "a choice filter needs op '==' and one of the question's labels",
                '{"question": "dept", "op": "==", "value": "billing"}',
            )
    elif not isinstance(value, (int, float)) or isinstance(value, bool):
        raise invalid(
            f"a {question['type']} filter needs a numeric value", "noul compares P(true), score the expected level"
        )
    return Filter(question=qid, op=op, value=value)


def resolve_format(fmt: str, path: Path) -> str:
    if fmt != "auto":
        return fmt
    suffix = path.suffix.lower()
    if suffix in (".jsonl", ".ndjson"):
        return "jsonl"
    return "csv" if suffix == ".csv" else "lines"


def load_items(
    params: BatchParams, *, path: Path | None, count_tokens: Callable[[str], int], max_items: int
) -> list[Item]:
    if params.items is not None:
        return [Item(id=_own_id(state, n), n=n, state=state) for n, state in enumerate(params.items, start=1)]
    if path is None:
        raise invalid("'path' was not checked", "this is a bug; please report it")
    text = path.read_text(encoding="utf-8", errors="replace")
    fmt = resolve_format(params.format, path)
    if fmt == "jsonl":
        items = _jsonl_items(text, params.field)
    elif fmt == "csv":
        items = _csv_items(text, params.field)
    elif fmt == "lines":
        items = [Item(id=n, n=n, state=line) for n, line in enumerate(text.splitlines(), start=1) if line.strip()]
    else:
        items = _chunk_items(text, params.chunk_tokens, count_tokens)
    if not items:
        raise invalid(f"{path} has no items", "check the format and that the file is not empty")
    if len(items) > max_items:
        raise too_large(f"{path} has {len(items)} items; the limit is {max_items}", "split the file")
    return items


def _own_id(value: Any, fallback: int) -> Any:
    return value["id"] if isinstance(value, dict) and "id" in value else fallback


def _as_state(value: Any) -> Any:
    if isinstance(value, (str, dict, list)) and value != "":
        return value
    return json.dumps(value)


def _jsonl_items(text: str, field: str | None) -> list[Item]:
    items = []
    for line_no, line in enumerate(text.splitlines(), start=1):
        if not line.strip():
            continue
        try:
            value = json.loads(line)
        except json.JSONDecodeError as exc:
            raise invalid(f"line {line_no} is not valid JSON: {exc.msg}", "each line must hold one JSON value") from exc
        state = _lookup(value, field, line_no) if field else value
        items.append(Item(id=_own_id(value, line_no), n=line_no, state=_as_state(state)))
    return items


def _lookup(value: Any, dotted: str, line_no: int) -> Any:
    for part in dotted.split("."):
        if not isinstance(value, dict) or part not in value:
            raise invalid(f"line {line_no} has no field {dotted!r}", "check the 'field' path")
        value = value[part]
    return value


def _csv_items(text: str, field: str | None) -> list[Item]:
    reader = csv.DictReader(io.StringIO(text))
    columns = reader.fieldnames or []
    if not columns:
        raise invalid("the CSV file has no header row", "the first line must name the columns")
    if field is not None and field not in columns:
        raise invalid(f"column {field!r} not found", f"columns: {', '.join(columns)}")
    items = []
    for n, row in enumerate(reader, start=1):
        state = row[field] if field is not None else {key: value for key, value in row.items() if key is not None}
        items.append(Item(id=row.get("id") or n, n=n, state=_as_state(state)))
    return items


def _chunk_items(text: str, chunk_tokens: int, count_tokens: Callable[[str], int]) -> list[Item]:
    items: list[Item] = []
    buffer: list[str] = []
    buffer_tokens = 0
    start: int | None = None

    def flush(end_line: int) -> None:
        nonlocal buffer, buffer_tokens, start
        body = "\n".join(buffer)
        if body.strip() and start is not None:
            items.append(
                Item(id=f"{start}-{end_line}", n=len(items) + 1, state=body, start_line=start, end_line=end_line)
            )
        buffer, buffer_tokens, start = [], 0, None

    lines = text.splitlines()
    for line_no, line in enumerate(lines, start=1):
        tokens = count_tokens(line) if line.strip() else 0
        if tokens > chunk_tokens:
            flush(line_no - 1)
            pieces = math.ceil(tokens / chunk_tokens)
            size = math.ceil(len(line) / pieces)
            for index in range(pieces):
                piece = line[index * size : (index + 1) * size]
                if piece.strip():
                    items.append(
                        Item(
                            id=f"{line_no}-{line_no}#{index + 1}",
                            n=len(items) + 1,
                            state=piece,
                            start_line=line_no,
                            end_line=line_no,
                        )
                    )
            continue
        if buffer and buffer_tokens + tokens > chunk_tokens:
            flush(line_no - 1)
        if start is None:
            start = line_no
        buffer.append(line)
        buffer_tokens += tokens
    flush(len(lines))
    return items


def passes(flt: Filter | None, answers: dict[str, dict[str, Any]]) -> bool:
    if flt is None:
        return True
    answer = answers[flt.question]
    if answer["type"] == "choice":
        return answer["choice"] == flt.value
    value = answer["noul"] if answer["type"] == "noul" else answer["score"]
    if flt.op == ">=":
        return value >= flt.value
    if flt.op == "<=":
        return value <= flt.value
    return value == flt.value


def select_matches(records: list[dict[str, Any]], flt: Filter | None, top_k: int) -> list[dict[str, Any]]:
    matching = [record for record in records if passes(flt, record["answers"])]
    if flt is not None:
        matching.sort(key=lambda record: record["answers"][flt.question]["answer_confidence"], reverse=True)
    return matching[:top_k]


def summarize(records: list[dict[str, Any]], questions: dict[str, dict[str, Any]]) -> dict[str, Any]:
    summary: dict[str, Any] = {}
    for qid, question in questions.items():
        answers = [record["answers"][qid] for record in records]
        if question["type"] == "choice":
            counts = dict.fromkeys(question["criteria"], 0)
            for answer in answers:
                counts[answer["choice"]] = counts.get(answer["choice"], 0) + 1
            summary[qid] = {"type": "choice", "counts": counts}
        elif question["type"] == "noul":
            values = [answer["noul"] for answer in answers]
            summary[qid] = {
                "type": "noul",
                "yes": sum(value >= 0.5 for value in values),
                "no": sum(value < 0.5 for value in values),
                "mean": round(sum(values) / len(values), 4),
            }
        else:
            histogram: dict[str, int] = {}
            for answer in answers:
                probabilities = answer.get("probabilities") or {}
                level = (
                    max(probabilities, key=probabilities.get) if probabilities else str(round(answer["score"]))
                )
                histogram[level] = histogram.get(level, 0) + 1
            scores = [answer["score"] for answer in answers]
            summary[qid] = {
                "type": "score",
                "histogram": dict(sorted(histogram.items(), key=lambda kv: int(kv[0]))),
                "mean": round(sum(scores) / len(scores), 4),
            }
    return summary


def aggregate_warnings(records: list[dict[str, Any]]) -> list[str]:
    counts: dict[str, int] = {}
    for record in records:
        keys = {
            f"{qid}: {warning_code(warning)}"
            for qid, answer in record["answers"].items()
            for warning in answer.get("warnings", [])
        }
        for key in keys:
            counts[key] = counts.get(key, 0) + 1
    return [f"{key} in {count} of {len(records)} items" for key, count in sorted(counts.items())]


def snippet(state: Any) -> str:
    text = state if isinstance(state, str) else json.dumps(state, ensure_ascii=False)
    return text[:SNIPPET_CHARS]


def public_record(record: dict[str, Any], *, include_warnings: bool = False) -> dict[str, Any]:
    out: dict[str, Any] = {
        "id": record["id"],
        "n": record["n"],
        "snippet": record["snippet"],
        "answers": compact_answers(record["answers"]),
    }
    if record.get("start_line") is not None:
        out["start_line"] = record["start_line"]
        out["end_line"] = record["end_line"]
    if include_warnings:
        out["checkpoint"] = record.get("checkpoint")
        out["warnings"] = [
            f"{qid}: {warning}" for qid, answer in record["answers"].items() for warning in answer.get("warnings", [])
        ]
    return out


def write_results(results_dir: Path, records: list[dict[str, Any]]) -> Path:
    results_dir.mkdir(parents=True, exist_ok=True)
    path = results_dir / f"{datetime.now(UTC):%Y%m%dT%H%M%SZ}-{secrets.token_hex(4)}.jsonl"
    with path.open("w", encoding="utf-8") as fh:
        for record in records:
            fh.write(json.dumps(public_record(record, include_warnings=True), ensure_ascii=False, default=str) + "\n")
    return path


def cleanup_results(
    results_dir: Path, *, max_age_seconds: float = RESULT_MAX_AGE_SECONDS, now: float | None = None
) -> int:
    if not results_dir.exists():
        return 0
    cutoff = (time.time() if now is None else now) - max_age_seconds
    removed = 0
    for path in results_dir.glob("*.jsonl"):
        if path.stat().st_mtime < cutoff:
            path.unlink()
            removed += 1
    return removed
```

```python
"""A rotating JSONL log with one line per decision: metadata only, unless log_inputs is on."""

from __future__ import annotations

import json
import logging
from datetime import UTC, datetime
from logging.handlers import RotatingFileHandler
from pathlib import Path
from typing import Any

from local_jev.guard import compact_answers


class DecisionLog:
    def __init__(
        self, log_dir: Path, *, log_inputs: bool, max_bytes: int = 10 * 1024 * 1024, backups: int = 5
    ) -> None:
        log_dir.mkdir(parents=True, exist_ok=True)
        self.path = log_dir / "decisions.jsonl"
        self._log_inputs = log_inputs
        self._handler = RotatingFileHandler(self.path, maxBytes=max_bytes, backupCount=backups, encoding="utf-8")
        self._handler.setFormatter(logging.Formatter("%(message)s"))
        self._logger = logging.getLogger(f"local_jev.decisions.{id(self)}")
        self._logger.setLevel(logging.INFO)
        self._logger.propagate = False
        self._logger.addHandler(self._handler)

    def record(
        self,
        *,
        interface: str,
        kind: str,
        response: dict[str, Any] | None,
        questions: dict[str, dict[str, Any]],
        latency_ms: float,
        state: Any = None,
        extra: dict[str, Any] | None = None,
    ) -> None:
        entry: dict[str, Any] = {
            "ts": datetime.now(UTC).isoformat(timespec="milliseconds"),
            "interface": interface,
            "kind": kind,
            "latency_ms": round(latency_ms, 1),
            "questions": [{"id": qid, "type": question["type"]} for qid, question in questions.items()],
        }
        if response is not None:
            local = response.get("local", {})
            entry.update(
                model=response.get("model"),
                backend=local.get("backend"),
                checkpoint=local.get("checkpoint"),
                answers=compact_answers(response["answers"]),
                input_tokens=response["usage"]["input_tokens"],
                warnings=local.get("warnings", []),
            )
        if extra:
            entry.update(extra)
        if self._log_inputs:
            entry["state"] = state
            entry["question_definitions"] = questions
        self._logger.info(json.dumps(entry, ensure_ascii=False, default=str))

    def close(self) -> None:
        self._logger.removeHandler(self._handler)
        self._handler.close()
```

```python
"""DecisionService: the one place REST and MCP requests are handled."""

from __future__ import annotations

import asyncio
import logging
import os
import resource
import threading
import time
from collections.abc import Callable
from typing import Any, NoReturn

from local_jev import __version__
from local_jev.batch import (
    Item,
    aggregate_warnings,
    cleanup_results,
    load_items,
    parse_batch_params,
    public_record,
    select_matches,
    snippet,
    summarize,
    write_results,
)
from local_jev.config import Settings
from local_jev.decision_log import DecisionLog
from local_jev.engines.base import Engine, EngineResult
from local_jev.errors import BusyError, ModelUnavailable, RuntimeTimeout, ServiceError, too_large
from local_jev.guard import finalize, prepare_questions
from local_jev.runtime import Runtime
from local_jev.schema import parse_decide_request
from local_jev.security import FilePolicy

logger = logging.getLogger(__name__)
TOKEN_BUDGET_HINT = "shorten option descriptions or split into two questions"


def translate(exc: BaseException) -> ServiceError | None:
    """Map engine and runtime exceptions onto ServiceError; None for anything unexpected."""
    if isinstance(exc, ServiceError):
        return exc
    if isinstance(exc, BusyError):
        return ServiceError(529, "busy", str(exc), "retry with exponential backoff")
    if isinstance(exc, RuntimeTimeout):
        return ServiceError(504, "timeout", str(exc), "retry; the first call after an idle period loads the model")
    if isinstance(exc, ModelUnavailable):
        return ServiceError(503, "model_unavailable", exc.message, exc.hint)
    if isinstance(exc, ValueError):
        message = str(exc)
        hint = TOKEN_BUDGET_HINT if "token budget" in message else "check the questions against the Jev schema"
        return ServiceError(422, "invalid_request", message, hint)
    return None


def _raise_translated(exc: BaseException) -> NoReturn:
    translated = translate(exc)
    if translated is None or translated is exc:
        raise exc
    raise translated from exc


class DecisionService:
    def __init__(
        self,
        settings: Settings,
        engine: Engine,
        *,
        runtime: Runtime | None = None,
        log: DecisionLog | None = None,
        clock: Callable[[], float] = time.monotonic,
    ) -> None:
        self.settings = settings
        self.engine = engine
        self.runtime = runtime or Runtime(
            engine, queue_limit=settings.queue_limit, idle_unload_seconds=settings.idle_unload_minutes * 60
        )
        self.log = log or DecisionLog(settings.log_dir, log_inputs=settings.log_inputs)
        self.prefetch_thread: threading.Thread | None = None
        self._files = FilePolicy(settings.batch.allowed_roots, settings.batch.max_file_bytes)
        self._clock = clock
        self._janitor: asyncio.Task[None] | None = None

    async def start(self) -> None:
        removed = cleanup_results(self.settings.results_dir)
        if removed:
            logger.info("removed %d result files older than 7 days", removed)
        self._janitor = asyncio.create_task(self._janitor_loop())
        names = self.settings.laya.prefetch
        if names:
            self.prefetch_thread = threading.Thread(
                target=self._prefetch, args=(names,), name="local-jev-prefetch", daemon=True
            )
            self.prefetch_thread.start()

    async def stop(self) -> None:
        if self._janitor is not None:
            self._janitor.cancel()
        self.runtime.shutdown()
        self.log.close()

    async def decide(self, body: Any, *, interface: str) -> dict[str, Any]:
        request = parse_decide_request(body)
        prepared = self._prepare(request.questions)
        start = self._clock()
        result = await self._run(
            lambda engine: engine.decide(request.state, prepared, request.model),
            timeout=self.settings.request_timeout_seconds,
            kind="decide",
        )
        latency_ms = (self._clock() - start) * 1000
        response = self._finalize(result, request.questions, latency_ms)
        self.log.record(
            interface=interface,
            kind="decide",
            response=response,
            questions=request.questions,
            latency_ms=latency_ms,
            state=request.state,
        )
        return response

    async def decide_batch(self, body: Any, *, interface: str) -> dict[str, Any]:
        cfg = self.settings.batch
        params = parse_batch_params(body, max_items=cfg.max_items)
        path = self._files.check(params.path) if params.path is not None else None
        try:
            items = await asyncio.to_thread(
                load_items,
                params,
                path=path,
                count_tokens=lambda text: self.engine.count_tokens(text, params.model),
                max_items=cfg.max_items,
            )
        except Exception as exc:
            _raise_translated(exc)
        evaluations = len(items) * len(params.questions)
        if evaluations > cfg.max_evaluations:
            raise too_large(
                f"{len(items)} items x {len(params.questions)} questions = {evaluations} evaluations; "
                f"the limit is {cfg.max_evaluations}",
                "ask fewer questions or split the file",
            )
        prepared = self._prepare(params.questions)
        start = self._clock()
        deadline = start + cfg.timeout_seconds
        records: list[dict[str, Any]] = []
        for offset in range(0, len(items), cfg.group_size):
            group = items[offset : offset + cfg.group_size]
            remaining = deadline - self._clock()
            if remaining <= 0:
                raise ServiceError(
                    504,
                    "timeout",
                    f"the batch ran past {cfg.timeout_seconds:g} s after {len(records)} of {len(items)} items",
                    "split the batch or ask fewer questions",
                )
            results = await self._run(
                lambda engine, group=group: [engine.decide(item.state, prepared, params.model) for item in group],
                timeout=remaining,
                kind="batch",
            )
            for item, result in zip(group, results, strict=True):
                records.append(self._record(item, self._finalize(result, params.questions, 0.0)))
        latency_ms = (self._clock() - start) * 1000
        output_path = write_results(self.settings.results_dir, records)
        matches = [public_record(record) for record in select_matches(records, params.filter, params.top_k)]
        out = {
            "count": len(records),
            "summary": summarize(records, params.questions),
            "matches": matches,
            "output_path": str(output_path),
            "warnings": aggregate_warnings(records),
            "latency_ms": round(latency_ms, 1),
        }
        self.log.record(
            interface=interface,
            kind="batch",
            response=None,
            questions=params.questions,
            latency_ms=latency_ms,
            state=params.path or "(inline items)",
            extra={
                "items": len(records),
                "matches": len(matches),
                "output_path": str(output_path),
                "backend": self.engine.name,
            },
        )
        return out

    def status(self) -> dict[str, Any]:
        s = self.settings
        return {
            "version": __version__,
            "pid": os.getpid(),
            "backend": self.engine.name,
            "engine": self.engine.status(),
            "runtime": self.runtime.stats(),
            "memory": {"peak_rss_mb": round(resource.getrusage(resource.RUSAGE_SELF).ru_maxrss / 2**20, 1)},
            "config": {
                "port": s.port,
                "noul_mode": s.noul_mode,
                "idle_unload_minutes": s.idle_unload_minutes,
                "log_inputs": s.log_inputs,
                "token_required": s.token is not None,
            },
        }

    def _prepare(self, questions: dict[str, dict[str, Any]]) -> dict[str, dict[str, Any]]:
        return prepare_questions(
            questions, noul_mode=self.settings.noul_mode, laya_guards=self.engine.capabilities.laya_guards
        )

    def _finalize(
        self, result: EngineResult, questions: dict[str, dict[str, Any]], latency_ms: float
    ) -> dict[str, Any]:
        try:
            return finalize(result, questions, backend=self.engine.name, latency_ms=latency_ms)
        except ModelUnavailable as exc:
            _raise_translated(exc)

    @staticmethod
    def _record(item: Item, response: dict[str, Any]) -> dict[str, Any]:
        return {
            "id": item.id,
            "n": item.n,
            "start_line": item.start_line,
            "end_line": item.end_line,
            "snippet": snippet(item.state),
            "checkpoint": response["local"]["checkpoint"],
            "answers": response["answers"],
        }

    async def _run(self, job: Callable[[Engine], Any], *, timeout: float, kind: str) -> Any:
        try:
            return await self.runtime.run(job, timeout=timeout, kind=kind)
        except Exception as exc:
            _raise_translated(exc)

    def _prefetch(self, names: tuple[str, ...]) -> None:
        try:
            self.engine.prefetch(names)
        except Exception:
            logger.exception("prefetching %s failed; run `local-jev pull` to retry", ", ".join(names))

    async def _janitor_loop(self) -> None:
        seconds = self.runtime.idle_unload_seconds
        interval = min(30.0, max(1.0, seconds / 2)) if seconds > 0 else 30.0
        while True:
            await asyncio.sleep(interval)
            self.runtime.check_idle()
```

```python
- path: absolute path to a local file. format: "jsonl" (one JSON object per line; field = dotted path to the text), "csv" (field = column), "lines" (one item per non-empty line), "chunks" (a long text split into pieces of about chunk_tokens tokens, with line ranges) or "auto" (by file extension).

Expect roughly 20-50 items per second per question on this Mac."""

STATUS_DESCRIPTION = (
    "Report the backend, loaded and downloaded checkpoints, queue depth, latency percentiles and configuration. "
    "Never loads a model."
)


def build_mcp_server(service: Any) -> MCPServer:
    mcp = MCPServer(name="local-jev", instructions=INSTRUCTIONS, version=__version__)

    @mcp.tool(description=DECIDE_DESCRIPTION)
    async def decide(
        state: str | dict[str, Any] | list[Any],
        questions: dict[str, dict[str, Any]],
        model: str = "auto",
    ) -> dict[str, Any]:
        return await _call(service.decide({"state": state, "questions": questions, "model": model}, interface="mcp"))

    @mcp.tool(description=BATCH_DESCRIPTION)
    async def decide_batch(
        questions: dict[str, dict[str, Any]],
        path: str | None = None,
        items: list[Any] | None = None,
        format: Literal["auto", "jsonl", "csv", "lines", "chunks"] = "auto",
        field: str | None = None,
        chunk_tokens: int = 256,
        filter: dict[str, Any] | None = None,
        top_k: int = 20,
        model: str = "auto",
    ) -> dict[str, Any]:
        body: dict[str, Any] = {
            "questions": questions,
            "format": format,
            "chunk_tokens": chunk_tokens,
            "top_k": top_k,
            "model": model,
        }
        for key, value in (("path", path), ("items", items), ("field", field), ("filter", filter)):
            if value is not None:
                body[key] = value
        return await _call(service.decide_batch(body, interface="mcp"))

    @mcp.tool(description=STATUS_DESCRIPTION)
    async def status() -> dict[str, Any]:
        return service.status()

    return mcp


async def _call(awaitable: Awaitable[dict[str, Any]]) -> dict[str, Any]:
    try:
        return await awaitable
    except ServiceError as exc:
        raise ToolError(exc.for_model()) from exc
```

```python
"""Jev-compatible REST routes: /v1/systemone, /v1/batch, /v1/status and /health."""

from __future__ import annotations

import json
from collections.abc import Awaitable, Callable
from typing import Any

from starlette.requests import Request
from starlette.responses import JSONResponse, Response
from starlette.routing import Route

from local_jev.errors import ServiceError, invalid, too_large

MAX_BODY_BYTES = 5 * 1024 * 1024


def build_rest_routes(service: Any) -> list[Route]:
    async def health(request: Request) -> Response:
        return JSONResponse({"ok": True})

    async def systemone(request: Request) -> Response:
        return await _guarded(request, lambda body: service.decide(body, interface="rest"))

    async def batch(request: Request) -> Response:
        return await _guarded(request, lambda body: service.decide_batch(body, interface="rest"))

    async def status(request: Request) -> Response:
        return JSONResponse(service.status())

    return [
        Route("/health", health, methods=["GET"]),
        Route("/v1/systemone", systemone, methods=["POST"]),
        Route("/v1/batch", batch, methods=["POST"]),
        Route("/v1/status", status, methods=["GET"]),
    ]


async def _guarded(request: Request, handler: Callable[[Any], Awaitable[dict[str, Any]]]) -> Response:
    try:
        body = await _read_json(request)
        return JSONResponse(await handler(body))
    except ServiceError as exc:
        return JSONResponse(exc.to_dict(), status_code=exc.status)


async def _read_json(request: Request) -> Any:
    declared = request.headers.get("content-length", "")
    if declared.isdigit() and int(declared) > MAX_BODY_BYTES:
        raise too_large(f"the body is {declared} bytes; the limit is {MAX_BODY_BYTES}", "use decide_batch with a path")
    raw = await request.body()
    if len(raw) > MAX_BODY_BYTES:
        raise too_large(f"the body is {len(raw)} bytes; the limit is {MAX_BODY_BYTES}", "use decide_batch with a path")
    try:
        return json.loads(raw)
    except (json.JSONDecodeError, UnicodeDecodeError) as exc:
        raise invalid(f"the body is not valid JSON: {exc}", "send a JSON object") from exc
```

```python
"""Assemble the Starlette app: security middleware, REST routes, the MCP endpoint and the lifespan."""

from __future__ import annotations

import os
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager

from starlette.applications import Starlette
from starlette.middleware import Middleware
from starlette.routing import Mount

from local_jev.api_mcp import build_mcp_server
from local_jev.api_rest import build_rest_routes
from local_jev.config import Settings
from local_jev.engines.base import Engine
from local_jev.security import SecurityMiddleware
from local_jev.service import DecisionService


def build_engine(settings: Settings) -> Engine:
    if settings.backend == "remote":
        from local_jev.engines.remote import RemoteJevEngine

        api_key = os.environ.get(settings.remote.api_key_env) if settings.remote.api_key_env else None
        return RemoteJevEngine(settings.remote.url, api_key=api_key, timeout=settings.request_timeout_seconds)
    from local_jev.engines.laya_mlx import LayaMLXEngine

    return LayaMLXEngine(settings.laya)


def create_app(settings: Settings, *, service: DecisionService | None = None) -> Starlette:
    service = service or DecisionService(settings, build_engine(settings))
    mcp = build_mcp_server(service)
    mcp_app = mcp.streamable_http_app(streamable_http_path="/mcp", host="127.0.0.1")

    @asynccontextmanager
    async def lifespan(_app: Starlette) -> AsyncIterator[None]:
        await service.start()
        try:
            async with mcp.session_manager.run():
                yield
        finally:
            await service.stop()

    return Starlette(
        routes=[*build_rest_routes(service), Mount("/", app=mcp_app)],
        middleware=[Middleware(SecurityMiddleware, port=settings.port, token=settings.token)],
        lifespan=lifespan,
    )
```

```python
"""Start local-jev at login with a per-user launchd agent."""

from __future__ import annotations

import os
import plistlib
import subprocess
from collections.abc import Callable
from pathlib import Path
from typing import Any

LABEL = "io.github.andresrubio.local-jev"


def plist_path(home: Path | None = None) -> Path:
    return (home or Path.home()) / "Library" / "LaunchAgents" / f"{LABEL}.plist"


def render_plist(program: list[str], log_dir: Path, env: dict[str, str]) -> bytes:
    data: dict[str, Any] = {
        "Label": LABEL,
        "ProgramArguments": list(program),
        "RunAtLoad": True,
        "KeepAlive": True,
        "ProcessType": "Background",
        "StandardOutPath": str(log_dir / "launchd.out.log"),
        "StandardErrorPath": str(log_dir / "launchd.err.log"),
    }
    if env:
        data["EnvironmentVariables"] = dict(env)
    return plistlib.dumps(data, sort_keys=True)


def install(
    program: list[str],
    log_dir: Path,
    env: dict[str, str],
    *,
    home: Path | None = None,
    run: Callable[..., Any] = subprocess.run,
) -> Path:
    path = plist_path(home)
    path.parent.mkdir(parents=True, exist_ok=True)
    log_dir.mkdir(parents=True, exist_ok=True)
    domain = f"gui/{os.getuid()}"
    run(["launchctl", "bootout", f"{domain}/{LABEL}"], check=False, capture_output=True)
    fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o600)
    with os.fdopen(fd, "wb") as fh:
        fh.write(render_plist(program, log_dir, env))
    path.chmod(0o600)
    run(["launchctl", "bootstrap", domain, str(path)], check=True)
    return path


def uninstall(*, home: Path | None = None, run: Callable[..., Any] = subprocess.run) -> bool:
    path = plist_path(home)
    run(["launchctl", "bootout", f"gui/{os.getuid()}/{LABEL}"], check=False, capture_output=True)
    if path.exists():
        path.unlink()
        return True
    return False
```

```python
def cmd_serve(args: argparse.Namespace, settings: Settings) -> int:
    import uvicorn

    from local_jev.app import create_app

    if args.port:
        settings = replace(settings, port=args.port)
    _configure_logging(settings.log_dir)

def cmd_pull(args: argparse.Namespace, settings: Settings) -> int:
    if settings.backend != "laya-mlx":
        print("pull only applies to the laya-mlx backend", file=sys.stderr)
        return 1
    from local_jev.checkpoints import CHECKPOINTS
    from local_jev.engines.laya_mlx import LayaMLXEngine

    names = tuple(CHECKPOINTS) if args.all else ("english", "multilingual")

def cmd_connect(args: argparse.Namespace, settings: Settings) -> int:
    url = f"http://127.0.0.1:{settings.port}/mcp"
    if args.harness == "claude-code":
        argv = ["claude", "mcp", "add", "--transport", "http", "--scope", "user"]

            argv += ["--header", f"Authorization: Bearer {settings.token}"]

            return 1
        return subprocess.run(argv, check=False).returncode

        return 1
    if args.harness == "codex":

        if settings.token:

    program = _serve_command()
    env = {"LOCAL_JEV_TOKEN": settings.token} if settings.token else {}

def cmd_uninstall_agent(args: argparse.Namespace, settings: Settings) -> int:

        return 1
    removed = launchd.uninstall()
    print("removed the login agent" if removed else "no login agent was installed")
    return 0


def _call(settings: Settings, method: str, path: str, payload: Any, *, timeout: float) -> int:
    url = f"http://127.0.0.1:{settings.port}{path}"
    headers = {"Authorization": f"Bearer {settings.token}"} if settings.token else {}
    try:
        status, body = _request(method, url, payload=payload, headers=headers, timeout=timeout)
    except httpx2.ConnectError:
        print(NOT_RUNNING, file=sys.stderr)
        return 1
    except httpx2.HTTPError as exc:
        print(f"request failed: {exc}", file=sys.stderr)
        return 1
    print(json.dumps(body, indent=2, ensure_ascii=False))
    return 0 if status == 200 else 1


def _request(method: str, url: str, *, payload: Any, headers: dict[str, str], timeout: float) -> tuple[int, Any]:
    response = httpx2.request(method, url, json=payload, headers=headers, timeout=timeout)
    try:
        return response.status_code, response.json()
    except ValueError:
        return response.status_code, {"error": {"code": "bad_response", "message": response.text[:500], "hint": ""}}


def _read_state(path: Path) -> Any:
    text = path.read_text(encoding="utf-8")
    return json.loads(text) if path.suffix.lower() == ".json" else text


def _read_json(path: Path) -> Any:
    return json.loads(path.read_text(encoding="utf-8"))


def _serve_command() -> list[str]:
    executable = shutil.which("local-jev")
    return [executable, "serve"] if executable else [sys.executable, "-m", "local_jev", "serve"]


def _confirm(question: str) -> bool:
    try:
        return input(f"{question} [y/N] ").strip().lower() in ("y", "yes")
    except EOFError:
        return False


def _configure_logging(log_dir: Path) -> None:
    log_dir.mkdir(parents=True, exist_ok=True)
    handler = RotatingFileHandler(log_dir / "server.log", maxBytes=10 * 1024 * 1024, backupCount=5, encoding="utf-8")
    handler.setFormatter(logging.Formatter("%(asctime)s %(levelname)s %(name)s: %(message)s"))
    logging.basicConfig(level=logging.INFO, handlers=[handler, logging.StreamHandler()])
```

```python
"""Start a throwaway local-jev server for the evaluation and benchmark scripts."""

from __future__ import annotations

import contextlib
import os
import socket
import subprocess
import sys
import tempfile
import time
from collections.abc import Iterator
from pathlib import Path

import httpx2


def free_port() -> int:
    with socket.socket() as sock:
        sock.bind(("127.0.0.1", 0))
        return sock.getsockname()[1]


@contextlib.contextmanager
def temporary_server(**env_overrides: str) -> Iterator[tuple[str, subprocess.Popen[bytes]]]:
    port = free_port()
    workdir = Path(tempfile.mkdtemp(prefix="local-jev-"))
    env = {
        **os.environ,
        "LOCAL_JEV_CONFIG": str(workdir / "none.toml"),
        "LOCAL_JEV_PORT": str(port),
        "LOCAL_JEV_NOUL_MODE": "native",
        "LOCAL_JEV_LOG_DIR": str(workdir / "logs"),
        "LOCAL_JEV_RESULTS_DIR": str(workdir / "results"),
        **env_overrides,
    }
    env.pop("LOCAL_JEV_TOKEN", None)
    stderr = (workdir / "stderr.log").open("wb")
    process = subprocess.Popen(
        [sys.executable, "-m", "local_jev", "serve"], env=env, stdout=subprocess.DEVNULL, stderr=stderr
    )
    base = f"http://127.0.0.1:{port}"
    try:
        deadline = time.monotonic() + 60
        while True:
            try:
                if httpx2.get(f"{base}/health", timeout=1).status_code == 200:
                    break
            except httpx2.HTTPError:
                pass
            if process.poll() is not None or time.monotonic() > deadline:
                raise RuntimeError(f"the server did not start; see {workdir / 'stderr.log'}")
            time.sleep(0.2)
        yield base, process
    finally:
        process.terminate()
        process.wait(timeout=30)
        stderr.close()


def wait_until_ready(base: str, names: tuple[str, ...] = ("english", "multilingual"), timeout: float = 900) -> dict:
    deadline = time.monotonic() + timeout
    while time.monotonic() < deadline:
        status = httpx2.get(f"{base}/v1/status", timeout=5).json()
        if set(names) <= set(status["engine"].get("ready", [])):
            return status
        time.sleep(1)
    raise RuntimeError(f"{names} were not ready within {timeout:.0f} s; run `local-jev pull` first")
```

```python
"""Accuracy on eval/items.jsonl for both yes/no label modes; writes eval/results.md.

Run `uv run python eval/run_eval.py` after `local-jev pull`. It starts its own temporary server.
"""

from __future__ import annotations

import json
import sys
from collections import defaultdict
from datetime import date
from pathlib import Path
from typing import Any

import httpx2

sys.path.insert(0, str(Path(__file__).resolve().parents[1] / "scripts"))
from _server import temporary_server, wait_until_ready  # noqa: E402

ITEMS = Path(__file__).with_name("items.jsonl")
RESULTS = Path(__file__).with_name("results.md")
AB_LABELS = {"true": "A", "false": "B"}


def predict(base: str, item: dict[str, Any], ab_labels: bool) -> tuple[Any, str]:
    question = dict(item["question"])
    if ab_labels:
        question["labels"] = AB_LABELS
    response = httpx2.post(
        f"{base}/v1/systemone", json={"state": item["state"], "questions": {"q": question}}, timeout=120
    )
    response.raise_for_status()
    body = response.json()
    answer = body["answers"]["q"]
    if question["type"] == "noul":
        guess: Any = answer["noul"] >= 0.5
    elif question["type"] == "choice":
        guess = answer["choice"]
    else:
        guess = int(max(answer["probabilities"], key=answer["probabilities"].get))
    return guess, body["local"]["checkpoint"]


def evaluate(base: str, items: list[dict[str, Any]]) -> dict[str, dict[str, list[int]]]:
    table: dict[str, dict[str, list[int]]] = {}
    for mode in ("native", "ab_labels"):
        stats: dict[str, list[int]] = defaultdict(lambda: [0, 0])
        for item in items:
            kind = item["question"]["type"]
            if mode == "ab_labels" and kind != "noul":
                continue
            guess, checkpoint = predict(base, item, ab_labels=mode == "ab_labels")
            correct = int(guess == item["expected"])
            keys = [kind, f"{kind} · {checkpoint}"] + (["noul · negations"] if item.get("negation") else [])
            for key in keys:
                stats[key][0] += correct
                stats[key][1] += 1
        table[mode] = dict(stats)
    return table


def render(table: dict[str, dict[str, list[int]]]) -> tuple[str, str]:
    native, ab = table["native"]["noul"], table["ab_labels"]["noul"]
    winner = "ab_labels" if ab[0] > native[0] else "native"
    lines = [
        f"# Evaluation ({date.today().isoformat()})",
        "",
        "60 hand-labelled items (`eval/items.jsonl`), 12 of them in Spanish, one question per request.",
        "",
    ]
    for mode, stats in table.items():
        lines += [f"## noul_mode = {mode}", "", "| Slice | Correct | Accuracy |", "|---|---|---|"]
        for key in sorted(stats):
            ok, total = stats[key]
            lines.append(f"| {key} | {ok}/{total} | {ok / total:.0%} |")
        lines.append("")
    lines.append(
        f"**Default `noul_mode`: `{winner}`.** Yes/no accuracy: native {native[0]}/{native[1]}, "
        f"ab_labels {ab[0]}/{ab[1]}. A tie goes to `native`."
    )
    return "\n".join(lines) + "\n", winner


def main() -> int:
    items = [json.loads(line) for line in ITEMS.read_text(encoding="utf-8").splitlines() if line.strip()]
    with temporary_server() as (base, _process):
        wait_until_ready(base)
        table = evaluate(base, items)
    text, winner = render(table)
    RESULTS.write_text(text, encoding="utf-8")
    print(text)
    print(f"winner: {winner}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
"""Latency, load time and memory of a temporary local-jev server; writes docs/benchmarks.md.

Run `uv run python scripts/bench.py` after `local-jev pull`.
"""

from __future__ import annotations

import platform
import re
import statistics
import subprocess
import sys
import time
from datetime import date
from importlib.metadata import version
from pathlib import Path

import httpx2
from _server import temporary_server, wait_until_ready

OUTPUT = Path(__file__).resolve().parents[1] / "docs" / "benchmarks.md"
ENGLISH = "I was billed twice for March, please refund one."
SPANISH = "Me han cobrado dos veces este mes, quiero que me devuelvan uno."
ONE = {"q": {"type": "noul", "instructions": "Does the customer ask for money back?"}}
TEN = {f"q{i}": {"type": "noul", "instructions": f"Does sentence {i} mention money?"} for i in range(10)}
UNITS_MB = {"B": 1 / 1024 / 1024, "K": 1 / 1024, "M": 1.0, "G": 1024.0}


def timed(base: str, state: str, questions: dict) -> float:
    start = time.perf_counter()
    response = httpx2.post(f"{base}/v1/systemone", json={"state": state, "questions": questions}, timeout=120)
    elapsed = (time.perf_counter() - start) * 1000
    response.raise_for_status()
    return elapsed


def footprint_mb(pid: int) -> float:
    """Physical footprint as `top` reports it; this includes the GPU buffers MLX allocated."""
    out = subprocess.check_output(["top", "-l", "1", "-pid", str(pid), "-stats", "mem"], text=True)
    value = out.strip().splitlines()[-1].strip().rstrip("+-")
    number = float(re.match(r"[\d.]+", value).group())
    return number * UNITS_MB.get(value[-1].upper(), 1.0)


def percentile(values: list[float], q: float) -> float:
    ordered = sorted(values)
    return ordered[min(len(ordered) - 1, round(q * (len(ordered) - 1)))]


def machine() -> str:
    chip = subprocess.check_output(["sysctl", "-n", "machdep.cpu.brand_string"], text=True).strip()
    memory_gb = int(subprocess.check_output(["sysctl", "-n", "hw.memsize"], text=True)) / 2**30
    return f"{chip}, {memory_gb:.0f} GB, macOS {platform.mac_ver()[0]}"


def main() -> int:
    with temporary_server(LOCAL_JEV_IDLE_UNLOAD_MINUTES="0.1") as (base, process):
        wait_until_ready(base)
        cold = timed(base, ENGLISH, ONE)
        one = [timed(base, ENGLISH, ONE) for _ in range(100)]
        ten = [timed(base, ENGLISH, TEN) for _ in range(50)]
        english_mb = footprint_mb(process.pid)
        timed(base, SPANISH, ONE)
        both_mb = footprint_mb(process.pid)
        time.sleep(15)  # idle unload after 6 s; the janitor checks every 3 s
        unloaded = httpx2.get(f"{base}/v1/status", timeout=5).json()["engine"]["loaded"] == []
        idle_mb = footprint_mb(process.pid)
        reload_ms = timed(base, ENGLISH, ONE)
    one_median, ten_median = statistics.median(one), statistics.median(ten)
    rows = [
        ("One short question, median", f"{one_median:.1f} ms", "≤ 100 ms", one_median <= 100),
        ("One short question, 95th percentile", f"{percentile(one, 0.95):.1f} ms", "", None),
        ("10 questions in one call, median", f"{ten_median:.1f} ms", "≤ 400 ms", ten_median <= 400),
        ("First request (loads English)", f"{cold:.0f} ms", "≤ 10,000 ms", cold <= 10_000),
        ("First request after idle unload", f"{reload_ms:.0f} ms", "≤ 10,000 ms", reload_ms <= 10_000),
        ("Memory with English loaded", f"{english_mb:.0f} MB", "", None),
        ("Memory with both checkpoints loaded", f"{both_mb:.0f} MB", "≤ 2,500 MB", both_mb <= 2500),
        ("Memory after idle unload", f"{idle_mb:.0f} MB", "≤ 400 MB", idle_mb <= 400),
        ("Models unloaded after idle", str(unloaded), "True", unloaded),
    ]
    lines = [
        f"# Benchmarks ({date.today().isoformat()})",
        "",
        f"Machine: {machine()}. laya-mlx {version('laya-mlx')}, local-jev {version('local-jev')}.",
        "Latency is end to end over HTTP from a local client. Memory is the process's physical footprint from `top`.",
        "",
        "| Measure | Result | Target | Pass |",
        "|---|---|---|---|",
    ]
    for name, result, target, ok in rows:
        mark = "" if ok is None else ("✅" if ok else "❌")
        lines.append(f"| {name} | {result} | {target} | {mark} |")
    OUTPUT.write_text("\n".join(lines) + "\n", encoding="utf-8")
    print("\n".join(lines))
    return 0 if all(ok is not False for *_, ok in rows) else 1


if __name__ == "__main__":
    sys.exit(main())
```

````markdown
# local-jev

Local, open-weight typed decisions in the style of TypeSafe's Jev. It runs [Laya](https://github.com/NandhaKishorM/laya) on Apple Silicon through [laya-mlx](https://github.com/mizorewww/laya-mlx). Agents reach it over MCP, a Jev-compatible REST API (`POST /v1/systemone`) or a CLI, and nothing leaves your Mac.

It answers three kinds of question about a piece of text or JSON, with probabilities and without generating text:

| Type | Answer |
|---|---|
| `noul` | P(yes) for a yes/no question |
| `choice` | The most likely option, with a probability for every option |
| `score` | The expected level on a rubric of 2–10 levels |

## Requirements

- A Mac with Apple Silicon, running macOS 14 or later.
- [uv](https://docs.astral.sh/uv/).
- About 1.5 GB of disk for the English and multilingual checkpoints, and about 2 GB of memory while both are loaded.

## Install

```bash
uv tool install --editable .
local-jev pull
```

`local-jev pull` downloads the English and multilingual weights (about 1.5 GB) and checks them against pinned checksums. `local-jev pull --all` also fetches the typed-decisions checkpoint. The weights come from `convaiinnovations/laya` at a pinned revision; see `src/local_jev/checkpoints.py`.

## Run

```bash
local-jev serve
```

`serve` runs in the foreground on http://127.0.0.1:7711.

```bash
local-jev install-agent
```

`install-agent` starts local-jev at login instead, through launchd. It asks before installing.

```bash
local-jev status
```

The server listens only on 127.0.0.1. It refuses requests addressed to other hosts or sent from web pages. Models load on first use and unload after 15 idle minutes.

## Connect an agent

```bash
local-jev connect
```

This prints `claude mcp add --transport http --scope user local-jev http://127.0.0.1:7711/mcp`. Add `--apply` to run it after a confirmation, or `--harness codex` (also `cursor` or `json`) for other agents.

Tools:

- **`decide(state, questions, model="auto")`:** one state, in Jev's request format.
- **`decide_batch(questions, path=... | items=[...], format, field, filter, top_k)`:** the same questions over many items. The items come from a local file (`jsonl`, `csv`, `lines`, or `chunks` of a long text) or an inline list. It returns counts, the best matches and a results file, so the items never enter the agent's context.
- **`status()`:** what the server is doing.

Agents that only run shell commands can use the CLI: `local-jev decide --state "..." --questions-file q.json` and `local-jev batch --questions-file q.json --path items.jsonl`.

## REST API

`POST /v1/systemone` accepts TypeSafe's documented request and returns the same answer fields, so an existing Jev client works when pointed at `http://127.0.0.1:7711`.

Differences from Jev:
- Each answer also has `answer_confidence` (the probability of the reported answer) and `warnings`.
- A `local` block reports the checkpoint, the routing reason, the latency and diagnostics.
- `model` is optional: `auto`, `english`, `multilingual` or `typed-decisions`. `jev-latest` means `auto`.
- Errors are `{"error": {"code", "message", "hint"}}`.

## What to expect

- Speed and memory on this Mac: [docs/benchmarks.md](docs/benchmarks.md).
- Accuracy on 60 hand-labelled items in English and Spanish: [eval/results.md](eval/results.md).

Laya is a small encoder (322–421M parameters), and it has limits:

- **Strengths and weaknesses:** good at simple classification and yes/no reading, weak at nuanced judgement unless fine-tuned on your own decisions.
- **Confidence:** probabilities are over-confident. Use them to rank answers, not as truth; confidence is not permission.
- **Input length:** the English checkpoint reads about 320 tokens of input and the multilingual one about 768. Answers carry a warning when the input was cut.
- **Weak spots:** negations ("don't cancel") and choices with more than about 20 options. More than 20 options are shortlisted automatically.
- **Untrusted text:** text in a state can steer the answer (prompt injection), so never use local-jev as the only check on untrusted input.

## Configuration

`~/.config/local-jev/config.toml`, where every key is optional:

```toml
port = 7711
backend = "laya-mlx"            # or "remote": any Jev-compatible /v1/systemone URL
idle_unload_minutes = 15        # 0 = never unload
noul_mode = "native"            # or "ab_labels": neutral A/B labels for yes/no questions
log_inputs = false              # true also logs the inputs, for training later

[laya]
dtype = "float16"
prefetch = ["english", "multilingual"]

[batch]
allowed_roots = ["~"]           # folders decide_batch may read

[remote]
url = ""                        # e.g. "http://127.0.0.1:8009/v1/systemone" for a Kev server
api_key_env = ""                # the environment variable that holds the remote API key
```

These environment variables override the file: `LOCAL_JEV_PORT`, `LOCAL_JEV_BACKEND`, `LOCAL_JEV_REMOTE_URL`, `LOCAL_JEV_IDLE_UNLOAD_MINUTES`, `LOCAL_JEV_NOUL_MODE`, `LOCAL_JEV_LOG_INPUTS`, `LOCAL_JEV_LOG_DIR`, `LOCAL_JEV_RESULTS_DIR` and `LOCAL_JEV_CONFIG`. Set `LOCAL_JEV_TOKEN` to require a bearer token on every request.

## Files

| Path | What |
|---|---|
| `~/Library/Logs/local-jev/server.log` | Server log |
| `~/Library/Logs/local-jev/decisions.jsonl` | One line per decision; metadata only unless `log_inputs` is on |
| `~/Library/Caches/local-jev/results/` | `decide_batch` result files, deleted after 7 days |
| `~/.cache/huggingface/hub/models--convaiinnovations--laya/` | Model weights |

## Uninstall

```bash
local-jev uninstall-agent
claude mcp remove --scope user local-jev
uv tool uninstall local-jev
```
````
